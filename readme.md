# Projeto sobre Consumo de APIs

Este mini projeto foi feito com o objetivo de entender mais sobre requisições de API, utilizando a biblioteca **requests** e entender sobre estruturação de classes.

## Pontos principais do código

* import da biblioteca **requests**
* API do studio ghibli
* Menu interativo

## Como rodar e requisitos:

Para que este código funcione, tenha certeza de ter baixado os arquivos **main.py** e **filmes.py**, após a instalação destes arquivos execute no terminal:

```bash 
python main.py
 ```

### Funções utilizadas

Dentro deste Projeto temos **duas funções principais**, uma que retorna todos os filmes contidos na API assim como suas informações (**buscarFilmes()**) e a função para buscar um filme pelo título (**buscarFilmePorTitulo()**) que retorna para o usuário as informações a partir de um título.

### Tecnologias utilizadas:
- Python 3.14
- Biblioteca requests
